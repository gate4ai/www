  1. 01

    Too much access

Rules per agent

Who, what, to whom and how much. Each agent gets its own token and profile, and one set of rules covers them all.

Passwords stay with you

Agents and connectors see aliases like @mail.work. gate4ai fills in the secret itself, only for the server it belongs to.

Proof for every action

Each request, decision and result goes to a tamper-evident journal. gate4ai journal verify checks it end to end.

Approve from anywhere

A desktop notification and the tray icon, Telegram, or the local Web UI. No answer in time means no.

Rules in plain words

Say what is fine. gate4ai holds the line.

“Email my accountant freely. Anyone else, ask me first.”

Trusted contacts go out at once; any other recipient waits for your tap.

- id: email-accountant
  action: email.send
  when: to.all(r, r in lists.contacts_trusted)
  effect: allow
- id: email-others
  action: email.send
  effect: ask

“Read my notes. Change them only after I approve in Telegram.”

Reading is silent; every edit becomes a message with Allow and Deny.

- id: notes-read
  action: files.read
  when: glob(path, "~/Documents/notes/**")
  effect: allow
- id: notes-append
  action: files.append
  when: glob(path, "~/Documents/notes/**")
  effect: ask

“Never write to an address the agent found in an incoming email. And no more than 20 emails a day.”

gate4ai tracks where each argument came from, so a planted address is refused.

- id: no-injected-recipients
  action: email.send
  when: "'untrusted_content' in provenance.to"
  effect: deny
limits:
  - { id: mail-per-day, action: email.send, per_day: 20 }

Built to be checked

You should not have to trust us. So you can verify.

  • Open source

    Core, relay, SDK and connectors are on GitHub. Core, relay and connectors are AGPL-3.0, the SDK is Apache-2.0.

  • Signed releases

    Checksums are signed with cosign; the installer refuses a tampered archive.

  • Signed connectors

    Packages are signed by the publisher, the store index by gate4.ai. Revoked versions do not install.

  • Local first

    No account and no cloud. Your rules, secrets and journal stay on your computer; the relay is optional.
