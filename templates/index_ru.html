Агентам отдают ключи от всего. Одного вредного письма хватает, чтобы это стало действиями.

  1. 01

    Слишком много доступа

    Персональный агент получает весь shell, залогиненный браузер и все файлы на диске. Нельзя сказать «только этот сайт, только эту папку».

  2. 02

    Prompt injection становится действием

    Страница или письмо со скрытой инструкцией может заставить агента переслать ваши данные или заплатить кому-то.

  3. 03

    «Сделано» без доказательств

    Агенты сообщают об успехе, которого не было. Без ответа сервера или скриншота это не проверить.

Два списка под вашим контролем

Сайты для Браузера, папки для Файлов, у каждой строки свой режим: разрешить, читать, спросить или запретить. Маски работают, побеждает самая конкретная строка, и каждый коннектор живёт внутри тех же списков.

Пароли остаются у вас

Агенты и коннекторы видят только алиасы вроде @bank.main. Входит на сайт сам gate4ai и только на тот, к которому привязана учётка.

Доказательство каждого действия

Запрос, решение и результат попадают в журнал, который нельзя незаметно изменить. gate4ai journal verify проверяет его целиком.

Подтверждение откуда угодно

Уведомление и значок в трее, Telegram или локальный Web UI. Не ответили вовремя — значит, нет.

Правила простыми словами

Скажите, что можно. Остальное gate4ai не пропустит.

«Банк читать можно. На сайте коммуналки — спрашивать перед каждым действием. Всё остальное закрыто».

Список сайтов, у каждого свой режим. Чтение проходит молча; всё, что больше чтения, на сайте ask ждёт вашего решения.

access:
  sites:
    - { domain: "*.bank.example", access: read }
    - { domain: "lk.example.org", access: ask }
    - { domain: "*", access: deny }

«Заметки читать и дописывать, но не переписывать. Загрузки — только через коннекторы, которые я поставил».

Список папок. append добавляет строки, не трогая написанное; connector не пускает агента напрямую, но пускает доверенный коннектор.

access:
  folders:
    - { path: "~/Documents/notes", access: append }
    - { path: "~/Downloads", access: connector }
    - { path: "~/.ssh", access: deny }

«Никогда не платить на счёт, который агент нашёл на веб-странице. И не больше 20 действий на страницах в день».

gate4ai помнит, откуда взялся каждый аргумент, поэтому подброшенный страницей получатель не пройдёт.

- id: no-injected-payees
  action: utilities.pay_bill
  when: "'untrusted_content' in provenance.payee"
  effect: deny
limits:
  - { id: acts-per-day, action: browser.act, per_day: 20 }

Можно проверить

Нам не нужно верить на слово. Всё можно проверить.

  • Открытый код

    Ядро с Браузером и Файлами, relay и SDK — на GitHub. Ядро и relay — под AGPL-3.0, SDK — под Apache-2.0.

  • Подписанные релизы

    Контрольные суммы подписаны cosign; подменённый архив установщик не поставит.

  • Подписанные коннекторы

    Коннекторы магазина — WASM-модули без доступа к сети; пакеты подписывает издатель, индекс магазина — gate4.ai. Отозванные версии не ставятся.

  • Всё у вас

    Ни аккаунта, ни облака. Правила, секреты и журнал остаются на вашем компьютере; relay необязателен.
