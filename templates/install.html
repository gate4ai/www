GATE4AI_VERSION=v0.1.1
{{if eq .Page.Lang.Code "ru"}}конкретная версия вместо последней{{else}}a specific version instead of the latest{{end}}
GATE4AI_INSTALL_DIR=…
{{if eq .Page.Lang.Code "ru"}}каталог установки (по умолчанию ~/.local/bin, на Windows %LOCALAPPDATA%\Programs\gate4ai){{else}}install folder (default ~/.local/bin, on Windows %LOCALAPPDATA%\Programs\gate4ai){{end}}
GATE4AI_NO_TRAY=1
{{if eq .Page.Lang.Code "ru"}}без значка в трее (серверы без графики){{else}}skip the tray icon app (headless servers){{end}}
GATE4AI_NO_START=1
{{if eq .Page.Lang.Code "ru"}}не включать автозапуск (gate4ai service install); запущенный daemon при обновлении всё равно перезапускается{{else}}do not turn on the autostart (gate4ai service install); a running daemon is still restarted on update{{end}}
GATE4AI_NO_OPEN=1
{{if eq .Page.Lang.Code "ru"}}не открывать мастер в браузере после установки (и так не открывается без графической сессии и при заданной CI){{else}}do not open the setup wizard in the browser after installing (it is not opened anyway without a graphical session or with CI set){{end}}
GATE4AI_INSTALL_DEPS=1
{{if eq .Page.Lang.Code "ru"}}поставить для браузера агентов Google Chrome, а на Linux без графики ещё виртуальный экран Xvfb и шрифты — без вопроса (по умолчанию gate4ai browser setup проверяет и спрашивает в терминале){{else}}install Google Chrome for the browser of agents, and on Linux without a screen also the Xvfb virtual screen and fonts, without asking (by default gate4ai browser setup checks them and asks at the terminal){{end}}
GATE4AI_NO_BROWSER=1
{{if eq .Page.Lang.Code "ru"}}не проверять Chrome сейчас (браузер встроен в gate4ai; позже — gate4ai browser setup){{else}}do not check Chrome now (the browser is built into gate4ai; later: gate4ai browser setup){{end}}
GATE4AI_NO_RELAY=1
{{if eq .Page.Lang.Code "ru"}}не включать доступ из интернета. По умолчанию daemon регистрирует компьютер на relay.gate4.ai и получает адрес https://<id>.relay.gate4.ai; relay видит только случайный id устройства и шифрованный трафик (TLS passthrough), больше с компьютера ничего не уходит. С этой переменной daemon стартует с выключенным доступом (relay.disabled); позже — gate4ai relay on | off{{else}}do not turn on access from the internet. By default the daemon registers this computer on relay.gate4.ai and gets https://<id>.relay.gate4.ai; the relay sees only a random device id and encrypted traffic (TLS passthrough), nothing else leaves the computer. With this variable the daemon starts with internet access off (relay.disabled); later: gate4ai relay on | off{{end}}
GATE4AI_UI_WAIT=3m
{{if eq .Page.Lang.Code "ru"}}сколько установщик ждёт адрес из интернета (регистрация на relay и выпуск сертификата) перед тем, как напечатать адреса и пароль; 0 — не ждать{{else}}how long the installer waits for the address from the internet (relay registration and certificate issue) before printing the addresses and the password; 0 — do not wait{{end}}
curl -fsSL https://gate4.ai/install.sh | GATE4AI_NO_TRAY=1 GATE4AI_NO_OPEN=1 GATE4AI_INSTALL_DEPS=1 sh

{{if eq .Page.Lang.Code "ru"}}Установка агентом (OpenClaw, Claude Code, Hermes){{else}}Installed by an agent (OpenClaw, Claude Code, Hermes){{end}}

{{if eq .Page.Lang.Code "ru"}}Установщик работает без терминала: ничего не спрашивает, недостающее для Chrome (библиотеки, Xvfb, шрифты) ставит сам, если он root или sudo работает без пароля, иначе печатает точные команды для root. В конце он печатает в stdout строки Web UI:, Password: и From the internet: — передайте их пользователю; адрес из интернета (https://<id>.relay.gate4.ai/ui/) открывается с любого устройства, проброс порта по ssh не нужен. Те же данные в любой момент: gate4ai ui --print (для программы — --json: url, password, remote_url, remote_cert). Пока сертификат адреса не выпущен, адрес работает на временном самоподписанном (remote_cert: temporary) — браузер предупредит, gate4ai сам заменит его настоящим. Под адресом установщик печатает, что видит relay (только случайный id и шифрованный трафик) и как выключить доступ: gate4ai relay off, при установке — GATE4AI_NO_RELAY=1; пользователей программы мы считаем по регистрациям на relay, больше ничего не собираем.{{else}}The installer works without a terminal: it asks nothing, installs what Chrome lacks (libraries, Xvfb, fonts) by itself when it is root or sudo works without a password, and otherwise prints the exact commands for root. At the end it prints Web UI:, Password: and From the internet: lines on stdout — pass them to the user; the address from the internet (https://<id>.relay.gate4.ai/ui/) opens from any device, no ssh port forwarding needed. The same data any time: gate4ai ui --print (for a program — --json: url, password, remote_url, remote_cert). Until the certificate for the address is issued, the address works on a temporary self-signed one (remote_cert: temporary): the browser warns about it, gate4ai replaces it with the real one by itself. Under the address the installer prints what the relay sees (only a random id and encrypted traffic) and how to turn it off: gate4ai relay off, at install GATE4AI_NO_RELAY=1; we count users of the program by relay registrations and collect nothing else.{{end}}

curl -fsSL https://gate4.ai/install.sh | GATE4AI_NO_TRAY=1 sh && gate4ai ui --print --json
